# MoodNomad · 情绪游牧

**在线演示：https://sn0w051201.github.io/-/**

演示站已通过 HTTPS 页面/资源检查，以及桌面和手机视口的浏览器渲染、PNG 下载和只读分享检查。当前是本地演示模式，数据仅保存在各自浏览器。

一个适配手机和电脑的旅行规划网页 MVP：**基础页面 → 行程 → AI 生成 → 记账分账 → 清单地图 → 分享海报**。

基于 React 19、TypeScript、Vite，参考「同行账本」的整数金额、稳定余数与账务分层思想，业务代码重新实现。暮山紫、沙丘米、落日橘主题。默认使用本地演示数据，**不需要微信 AppID、CloudBase 环境或模型 Key 就能运行完整流程**。

## 立即运行

需要 Node.js 22+ 和 npm。

```bash
npm ci
npm run dev
```

在浏览器打开终端显示的地址，默认端口 5173。当前是**网页项目**，不导入微信开发者工具；网页不需要微信 AppID。

```bash
npm run typecheck        # 前端/共享领域/服务端 TS
npm test                 # 金额、分账、结构、权限和模型适配测试
npm run build            # 生产网页，输出 dist/
npm run preview          # 查看生产构建
npm run build:cloud      # 生成 cloudfunctions/api/index.js
npm run test:e2e         # 桌面与移动视口浏览器回归
```

Playwright 默认使用 `/usr/bin/chromium`。其他环境先安装 Chromium，再设置 `CHROMIUM_PATH` 为实际可执行文件路径。移动项目是在 Chromium 中模拟 iPhone 尺寸，**不是 Safari/iOS 真机验证**。

## 已实现的演示流程

1. **基础页面**：响应式侧边导航、目的地搜索、旅行总览、个人昵称、加载/空/错误状态。两段可切换示例旅行。
2. **行程**：创建旅行、选择日期、活动增删改、上下排序、备注、预估费用、手动经纬度和打卡；本地演示旅伴添加与角色管理。
3. **AI 规划**：目的地、天数、全员总预算、节奏、兴趣；生成预览、保存全程/替换单日，明确区分规则示例与真实模型。
4. **记账分账**：账单增删改、付款人/指定参与人、平均/整数比例/指定金额三种分摊、消费分类、日期、备注、可选图片凭证；预算与分类统计、成员净余额、简化转账建议、当前账本“全员结清”标记。账单改变会使旧结清标记失效。
5. **清单地图**：公共/个人清单、负责人、准备日期、分类、完成筛选；按天地图标记和访问连线、打卡。默认离线示意图；主动开启可加载 Leaflet + OpenStreetMap 在线底图，失败时仍可回到示意图。没有持续定位或真实导航。
6. **分享海报**：Canvas 2D 生成 900×1200 PNG，行程或账单摘要、可选昵称、二维码、可复制只读摘要链接。账单海报默认隐藏消费细项和昵称。
7. **数据工具**：本地保存、JSON 导出/导入（有结构校验与替换确认）、恢复示例。存储失败会提示当前修改尚未持久化。

建议体验：创建成都 2 日游 → AI 示例攻略 → 保存并编辑 → 记一笔 100.01 元 → AA 分账 → 清单打卡 → 查看地图 → 保存海报。

## 数据模式与真实能力边界

### 本地模式（默认、已浏览器验证）

- `VITE_DATA_MODE=mock`：数据位于当前浏览器 `localStorage`，没有真实登录、跨设备协作或后端同步。
- AI 是确定性的规则示例，不调用模型、不收费。已知城市提供示例地点；未知城市不编造坐标。
- 凭证图片在浏览器压缩为 JPEG 后放入本地数据；存储空间有限，请备份。
- 分享链接在 URL fragment 内包含明确选择的摘要快照。**任何持有链接的人都可以查看，快照生成后无法撤销**，不用于分享敏感数据。
- 生成的旅行风景图片为灵感示意，不代表大理或杭州的实拍。地图和攻略均不提供实时事实。

### 云模式（代码及构建已验证，尚未真实部署验收）

复制 `.env.example` 为 Git 忽略的 `.env.local`：

```dotenv
VITE_DATA_MODE=cloud
VITE_CLOUDBASE_ENV_ID=你的云环境ID
```

前端通过 CloudBase SDK 调用 `api` 云函数。SDK 按需加载，本地模式不下载该 SDK。环境 ID 是客户端初始化所需的公开标识，但按项目约定仅写本地配置，不提交真实 ID。

云函数在可信上下文获取 UID，提供旅行保存、角色校验、乐观锁、账单作者/成员校验、邀请码、七天分享令牌与撤销、私有凭证上传和五分钟展示 URL，以及服务端大模型调用、严格 Zod 输出校验、最多一次重试、按用户日限额、五分钟用户隔离缓存和生成记录。

**仅在云函数环境中配置：**

```dotenv
LLM_API_KEY=通过云控制台安全填写
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
AI_DAILY_LIMIT=10
```

不要给密钥加 `VITE_` 前缀，否则 Vite 会把它打进浏览器包。不要把模型 Key、CloudBase 管理员 SecretId/SecretKey、微信 AppSecret 放到前端或代码库。

当前云登录使用 CloudBase 匿名身份，仅用于联调，同一浏览器可恢复会话；**不是微信登录，也不能保证换设备找回账号**。正式运营前应升级为正式身份登录并完成真实多账号、规则和跨设备验收。

## 金额与分账约定

所有存储、计算和服务端字段均使用人民币整数分。元输入使用十进制字符串解析，不用浮点数乘 100 得到权威金额。

- 平均分：按稳定成员 ID 升序分配余数，100 分 / 3 人得到 34、33、33 分。
- 比例分：整数权重 + 最大余数法；中间乘除使用 BigInt，避免较大权重引入精度损失。
- 指定金额：每人非负整数分，合计必须严格等于总额。
- 净余额 = 实付 − 应承担；按绝对金额降序、成员 ID 定序匹配债权债务。
- 转账建议确定、金额守恒，**不保证全局最少笔数**；不做真实支付。
- 账单含稳定 `idempotencyKey`，服务端拒绝重复键；版本冲突不会静默覆盖。不同版本重复保存会返回冲突，调用方保留表单而不是盲目重试。

## 目录

```text
src/
  components/         基础界面、对话框和状态组件
  pages/              总览、行程、AI、账本、清单地图、海报、设置、只读分享
  domain/             类型、整数金额、分账与共享结构校验
  services/           本地存储、规则攻略、CloudBase 适配、分享编码
  data/               可重置示例
server/               云函数入口、服务端权限与模型适配
cloudfunctions/api/   独立云函数 package.json / lockfile；生成的入口忽略入库
config/               数据库/存储规则、索引和部署模板
scripts/              云函数打包
tests/e2e/            桌面/手机浏览器流程
public/images/        本地旅行灵感图，不依赖外部图片网站
```

仓库没有真实密钥。`dist/`、本地配置、测试截图/追踪、安装目录和生成的云入口不提交。演示站已发布到 GitHub Pages；`npm run build` 的 `dist/` 也可部署到其他静态站点托管。
